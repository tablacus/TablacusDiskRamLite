
# Tabacus DISK RAM Lite for MSX Gaku

## 機能概略

このソフトはTablacus DISK ROM Lite (v0.7.4.1) をベースに、似非RAMディスクへの書き込みに対応させたものです。
v0.0.0.2からは、書き込み非対応(ROM専用/8KB本体)のビルドは廃止し、書き込み対応版(16KB本体)のみのシンプルな構成にしています。

## 注意事項

- 書き込み対応の為に本体サイズが8KBから16KBに倍増しています。
- 対応しているメガROMタイプは 8KバンクのメガROM(ASCII-8K / Konami-8K / Konami-SCC)に限定されます。

## ファイル構成

- `DISKRAM.ASM` / `DISKRAM64K.ASM` : ビルドのエントリポイント(BASIC用 / 似非DOS用)
- `DISKROM.ASM` : 共通のベース(ROMヘッダ、1バンク目/2バンク目の連結)
- `BANK1.ASM` : 2バンク目(セグメント#1)に常駐させるコード置き場
  - `DISK_WRITE_RAM` : 似非RAMディスクへの書き込みルーチン
  - `CHK_RAM`ほか : 起動時のみ使うRAM検出ルーチン
- `DEF.ASM` / `INIT.ASM` / `FILE.ASM` / `DISK.ASM` / `BDOS.ASM` / `TABLE.ASM` / `SLOT.ASM` : 1バンク目(セグメント#0、常駐ドライバ本体)

## バンク構成メモ

本体16KBは以下の2バンクで構成されています。

- **1バンク目(BANK0、4000h-5fffh、セグメント#0)**: 常駐ドライバ本体。常時マッピングされている。
- **2バンク目(セグメント#1)**: 普段はBANK1(6000h-7fffh、ディスクデータの読み出しウィンドウ)に他のセグメントがマッピングされているが、以下のタイミングだけ一時的にセグメント#1へ切り替えて`BANK1.ASM`のコードを実行する。
  - 似非RAMディスクへの書き込み時(`DISK_WRITE_RAM`)
  - 起動時のRAM検出時(`CHK_RAM`)

1バンク目(セグメント#0)が今後さらに手狭になっていく場合は、「頻繁に呼ばれない」「BANK1を他の目的で使っていないタイミングでしか呼ばれない」ルーチンを`BANK1.ASM`側へ追加で移していく方針です。
